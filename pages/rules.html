PROTOCOL DIRECTIVES

Strict adherence to the survival protocols is mandatory. Violators will be terminated from the mainframe.

  • Squad Size: Minimum 2, Maximum 4 operatives per team.
  • Duration: 24-hour continuous deployment.
  • Hardware: Operatives must utilize their own terminal devices (laptops). External drives containing pre-compiled code repositories are strictly forbidden.
  • Evaluation: AI bypass efficiency, UI/UX design, and core backend logic (PHP, JS, Ajax preferred).
  • Sanctions: Using external AI tools for more than 20% of the codebase will trigger an automatic disqualification sequence.

  • Weight Class: Machines must not exceed 15kg (including battery).
  • Dimensions: Maximum structural limit is 60cm x 60cm x 60cm.
  • Weaponry Restrictions: Untethered projectiles, EMP devices, liquids, and uncontained fire/heat weapons are universally banned.
  • Combat Format: 3-minute elimination rounds. The last functional machine survives.

  • Environment: Challenges are distributed across the campus local network and physical QR checkpoints.
  • Integrity Protocol: Attempting to DDoS the college server infrastructure will result in immediate campus security intervention.
  • Progression: Flags must be captured in sequential order. Skipping checkpoints is physically impossible.
  • Time Limit: Operatives have exactly 120 minutes to secure the final extraction code.

  • Format: 5v5 standard competitive matches (Valorant).
  • Hardware Setup: Peripherals (mice, keyboards, headsets) can be brought by operatives, but all config modifications must be done within the 10-minute setup window.
  • Fair Play: Exploitation of map glitches, usage of modified clients, or toxic behavior in all-chat will result in immediate squad elimination.
  • Map Pool: Decided via standard pick/ban phase before match initialization.
